# 字体颜色设计规范（终版）

> 基于项目 `frontend/src` 现有样式与设计讨论整合定稿。
> 本规范直接对应 Element Plus 组件库 + Vue 3 项目的实际 CSS 实现。

---

## 一、文字层级规范（Text Hierarchy）

整个前端界面的文字颜色遵循五级灰度体系，来自 Element Plus 标准色板：

| 层级 | 用途 | Hex | CSS 变量 | 设计说明 |
|-----|------|-----|---------|---------|
| **主要文字** | 标题、表头、技能名称、数值 | `#303133` | `--text-primary` | 最高对比度，保证可读性 |
| **次要文字** | 标签值、属性名、描述正文 | `#606266` | `--text-regular` | 中等对比度，区分层级 |
| **辅助文字** | 说明、提示、元数据 | `#909399` | `--text-secondary` | 低对比度，不干扰主内容 |
| **占位/禁用** | 空状态提示、禁用项 | `#c0c4cc` | `--text-placeholder` | 最低对比度 |
| **白色** | 深色背景上的文字、图标 | `#ffffff` | `--text-white` | 纯白，用于 `tag` 内部 |

### 代码库现状对应

| 项目文件 | 主要文字 | 次要文字 | 辅助文字 | 占位/禁用 |
|---------|---------|---------|---------|----------|
| SkillList.vue | 表头、技能名 `#303133` | 编辑提示 `#606266` | 副说明 `#909399` | 空帧状态 `#c0c4cc` |
| DpsSimulator.vue | 角色名、标签 `#303133` | 伤害公式 `#606266` | buff行、元数据 `#909399` | 选中行禁用提示 |
| LoadoutEditor.vue | 属性值 `#303133` | 属性标签 `#606266` | 倍率辅助 `#909399` | 空状态 `#c0c4cc` |
| TimelineEditor | 标题 `#303133` | 属性标签 `#606266` | 时间 `#909399` | 空状态 `#c0c4cc` |

## 四、状态色规范（Status Colors）

遵循 Element Plus 语义色板，用于操作反馈和状态标识：

| 状态 | Hex | Element Plus 变量 | 用途 |
|-----|-----|------------------|------|
| **成功/激活** | `#67c23a` | `--el-color-success` | buff已填入、增益已激活、Filled状态 |
| **警告/需更新** | `#e6a23c` | `--el-color-warning` | ⚠ 更新计算按钮、数据过期提示 |
| **危险/删除** | `#f56c6c` | `--el-color-danger` | 删除按钮、力竭/危险状态 |
| **信息/中性** | `#909399` | `--el-color-info` | 标签类型区分、中性提示 |
| **主要** | `#409eff` | `--el-color-primary` | 主要操作按钮、链接、选中状态 |

### 常见场景

| 场景 | 颜色 | 示例 |
|-----|------|------|
| 增益单元格已填入 | `#67c23a` | `.buff-cell.filled { color: #67c23a }` |
| 增益图标底色 | `#67c23a` | `.gain-icon { background: #67c23a }` |
| 处决/删除 | `#f56c6c` | 删除按钮 type="danger" |
| 暴击伤害数值 | `#f56c6c` | `.dc-final { color: #f56c6c }` 最终伤害 |
| 更新计算提示 | `#e6a23c` | `dirty ? 'warning' : 'primary'` |
| 选择/主要按钮 | `#409eff` | 模拟、保存等主要操作 |
| 时间轴吸附提示 | `#67c23a` | `.drop-time { color: #67c23a }` |

## 八、使用规范

1. **技能类型标签 (`<el-tag>`)** — 当展示技能类型时，使用 `type` 对应的 Element Plus tag type（success/warning/danger/info/primary）

2. **伤害类型文本** — 使用 `--dmg-*` 变量作为文字色，以区分不同元素

3. **数值标色** — 正收益（增益）使用 `--status-success`，负收益（减益/伤害）使用 `--status-danger`，中性使用 `--text-primary`

4. **禁用态** — 不可操作的按钮/输入使用 `--text-placeholder` + `cursor: not-allowed`

5. **浅色底色** — 技能卡片、行悬停使用对应的 `--skill-bg-*` 浅色背景，避免大面积使用饱和色造成视觉疲劳

6. **图表配色** — ECharts 饼图/柱状图优先使用本规范定义的色值数组，确保 UI 与图表颜色系统一致
