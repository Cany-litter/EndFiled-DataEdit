## 六、公式引擎 (9 模块)

### 6.1 攻击/面板/HP `attack.ts`

```typescript
calcAttack(input: AttackInput): number
  // raw = (baseAtk + weaponAtk) × (1 + atkPercent) + flatBonus
  // attrBonus = 1 + floor(mainAttr) × 0.005 + floor(subAttr) × 0.002
  // return raw × attrBonus

calcStat(input: StatInput): number
  // return (base + trustBonus + weaponBonus + equipBonus) × (1 + percentBonus)

calcHp(input: HpInput): number
  // return baseHp × (1 + percentBonus) + flatBonus
```

### 6.2 属性聚合 `stats.ts`

```typescript
calcFinalStats(char: CharConfig, weapon: WeaponConfig, equip: EquipStats): FinalStats
```

四维计算（str/agi/int/wil）：
- 基础值 + 信赖等级加成(1→10, 2→25, 3→40, 4→60) + 武器词条匹配值 + 装备值
- 主能力/副能力 = 对应的四维值
- 属性加成 = floor(主能力) × 0.005 + floor(副能力) × 0.002
- 攻击力 = (基础+武器) × (1+装备攻击%) × 属性加成
- HP = 基础HP × (1+装备HP%)
- 物理抗性 = floor(敏捷) > 0 ? 100 - 100/(0.001×floor(敏捷)+1) : 0
- 法术抗性 = floor(智识) > 0 ? 100 - 100/(0.001×floor(智识)+1) : 0

### 6.3 伤害计算 15 乘区 `damage.ts`

```typescript
calcDamage(input: DamageInput): DamageBreakdown
```

| # | 乘区 | 计算 |
|---|------|------|
| 1 | 基础 | attack × skillMultiplier + baseDamageFlat |
| 2 | 暴击 | 1 + critRate × critDamage |
| 3 | 增伤 | 1 + damageBonus |
| 4 | 减伤 | Π(1 - eachDamageReduction) |
| 5 | 增幅 | 1 + amplifyBonus |
| 6 | 虚弱 | Π(1 - eachWeaken) |
| 7 | 庇护 | 1 - shelterValue |
| 8 | 脆弱 | 1 + fragileBonus |
| 9 | 易伤 | 1 + vulnerableBonus |
| 10 | 防御 | trueDamage ? 1 : 1 - def/(def+100) |
| 11 | 失衡 | isStaggered ? staggerMultiplier(1.3) : 1 |
| 12 | 抗性 | 1 - resistance/100 + resistanceIgnore/100 |
| 13 | 非主控 | 1 - nonControlledReduction |
| 14 | 连击 | 1 + comboBonus |
| 15 | 特殊 | specialMultiplier |

最终伤害 = 基础 × 乘区2 × 乘区3 × ... × 乘区15

### 6.4 异常系统 `anomaly.ts`

```typescript
// 异常等级
calcAnomalyLevel(consumedStacks: number): number  // 1~4级

// 等级系数
calc法术等级系数(level): 1 + (level-1)/196
calc物理等级系数(level): 1 + (level-1)/392

// 源石技艺强度区
calc源石技艺强度区(value): 1 + value/100

// 法术异常伤害
calc法术异常伤害(input): baseMultiplier × (1+anomalyLevel) × 法术等级系数 × 源石技艺强度区

// 物理异常伤害
calc物理异常伤害(input): baseMultiplier × stackMult × 物理等级系数 × 源石技艺强度区

// 附带效果增强
calc附带效果增强(源石技艺强度): 2 × 强度 / (强度 + 300)
```

### 6.5 排轴引擎 `engine.ts`

单角色循环模拟：

```
while time < duration:
  1. 自动攻击检查（每1.5s触发，+5能量）
  2. 从循环序列取出下一个技能
  3. 冷却已到 && 能量满足 → 施放(施法时间后结算伤害)
  4. 否则等待0.1s
```

SkillConfig 使用优先级：`skill_action` 表真实数据 > `DEFAULT_SKILL_CONFIGS` 硬编码

### 6.6 配队排轴 `teamEngine.ts`

4 成员独立模拟（各自能量/冷却/自动攻击），结果汇总为团队 DPS。

### 6.7 效果解析引擎 `engine/formulas/effectResolver.ts`

从参考项目（编队总伤计算器）移植，支持四种 Buff 效果缩放模式：

| 模式 | 公式 |
|------|------|
| 固定值 | `value` |
| 线性缩放 | `min(stat × ratio, cap)` |
| 分段线性曲线 | `piecewiseLinear(stat, curve)` |
| 饱和缩放 | `value × (x + y×stat/(z+stat))` |

同时提供：
- `matchesCondition(condition, context)` — 按 skillType + element 条件过滤
- `collectCrit(activeBuffs, context, baseRate, baseDmg)` — 从 Buff 动态收集暴击属性
- `ARTS_INTENSITY_CURVE` — 源石技艺强度映射 `(0,1)→(500,6)`

### 6.8 分类驱动伤害计算 `engine/formulas/damageCategories.ts`

新增分类驱动计算模式，与原有 15 乘区并存：

```typescript
const DAMAGE_CATEGORIES: CategoryDef[] = [
  { key: 'DMG_Dealt', label: '增伤' },
  { key: 'DMG_Taken', label: '易伤' },
  { key: 'Susceptibility', label: '脆弱' },
  { key: 'Arts_Amp', label: '增幅' },
  { key: 'Resistance', label: '抗性' },
  { key: 'Link', label: '连击' },
  { key: 'Staggered', label: '失衡' },
  { key: 'Finisher', label: '处决' },
]

calcDamageByCategories(baseDamage, activeBuffs, categories, context)
// → { finalDamage, breakdown: { category: { label, contributions[], rawTotal, metas[], multiplier } } }
```

- Buff 按 `effects[].category` 分组到各乘区
- 每个乘区 `multiplier = 1 + rawTotal × Π(metaMultipliers)`
- 支持条件过滤（skillType/element）
- 支持 meta 元乘数

## 十、已知局限

- 装备副属性已解析 `str/agi/int/wil/atk%/hp%/def%/critRate/critDamage/damageBonus/artsMastery/energyRecharge`，但游戏实际词条可能更多
- 排轴引擎的冷却/能量消耗优先读取 `skill_action` 表，未找到时回退硬编码默认值
- `skill_action` 表数据可能不完整（取决于 AKEDB 数据源）
- 增益系统已扩展 `Buff` 接口支持 `effects[]`/`metas[]`，**但后端 Gain → 前端 EffectDef 的完整映射尚未在时间线 UI 中集成**
- 异常伤害系统已实现完整公式，但**尚未接入排轴引擎**
- `skill_action` 表数据可能不完整（取决于 AKEDB 数据源）
- 无用户认证系统（单机使用）
- 无 Excel 导入功能
- 套装效果(setEffect1/2)数据已入库，但**尚未在配装编辑器中实时计算**
- 无配装对比功能（并排 DPS 对比）
- 团队排轴尚未实现全队技力管理机制
- 连击增伤和源石技艺强度曲线已在 `teamEngine` 中实现，但**尚未在时间线引擎 `timeSimEngine` 的 base path 中生效**（需使用 `runTimelineSimulationWithDamage`）
- `character_stat` 成长数组原始数据包含 99 级数值（实际仅 1-90 级），导入时已截取前 90 级
