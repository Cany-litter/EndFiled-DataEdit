## 一、项目总览

全栈 Web 应用，前后端分离架构，用于《明日方舟：终末地》的数据管理与配装模拟。

| 层级 | 技术栈 |
|------|--------|
| **前端** | Vue 3.4 + TypeScript 5.4 + Vite 5.2 + Element Plus 2.7 + Pinia 2.3 + Vue Router 4.6 |
| **后端** | Spring Boot 2.7.18 + MyBatis-Plus 3.5.5 + Java 17 + Maven |
| **数据库** | MySQL 8.0 (9 张表) |
| **数据源** | AKEDatabase (GitHub RAW) |
| **构建** | `npm run build` ✅ 通过 |

## 六、公式引擎 (6 个模块)

| 模块 | 文件 | 功能 |
|------|------|------|
| 攻击/面板/HP | `attack.ts` | 攻击=(基础+武器)×(1+%)+固定×属性加成; HP=基础×(1+%)+固定; 属性=总和×(1+%) |
| 属性聚合 | `stats.ts` | `calcFinalStats` → 攻击/HP/四维/属性加成/防御%/暴击率/爆伤/增伤% |
| 伤害计算 | `damage.ts` | 15 乘区连乘: 基础×暴击×增伤×减伤×易伤×虚弱×庇护× fragility×vulnerable×防御×踉跄×抗性×非受控×连击×特殊 |
| 异常系统 | `anomaly.ts` | 异常等级(4档)、等级系数(法术/物理)、源石技艺强度区、异常伤害(6法术+4物理)、附带效果增强、连击增伤表 |
| 排轴引擎 | `engine.ts` | 单角色: 循环序列→自动攻击→能量/冷却→DPS |
| 配队排轴 | `teamEngine.ts` | 四人独立: 各自循环/能量/冷却→团队DPS |

## 七、配装编辑器 (核心功能)

**LoadoutEditor.vue** — 双面板布局:

**左面板 (选择+面板)**:
- 角色下拉 (稀有度+职业)
- 武器过滤 (按角色武器类型)
- 4 装备槽 (护甲/护手/配件x2) + 套装检测
- 实时面板: 攻击/HP/四维/防御%/暴击%/爆伤%/增伤%/属性加成

**右面板 (技能伤害)**:
- 标签页切换 (普攻/战技/连携/终结技)
- 等级滑条 1-12
- 伤害乘区明细表 (基础/暴击/增伤/防御/抗性/连击/最终)
- 可配置战斗参数 (暴击率/爆伤/增伤/防御/抗性/穿透)

**操作**: 保存方案 / 导出Excel(含乘区明细) / 加载已存方案

## 八、排轴模拟 (v2.0)

### 单角色模拟 (`/simulator`)
- 选择配装方案 → 加载角色技能
- 构建循环序列 (从可用技能增删)
- 配置: 时长/目标数/防御/抗性/暴击/爆伤/增伤
- 引擎: 自动攻击(1.5s+5能量) → 能量管理(上限100) → 冷却追踪
- 结果: DPS + 总伤害 + 施放次数 + 技能伤害占比 + 时间线(前30s)

### 配队排轴 (`/team-sim`)
- 选择已存配队 → 加载4角色+配装
- 每角色独立设置循环序列
- 引擎: 4角色各自模拟 (独立能量/冷却/自动攻击)
- 结果: 团队DPS + 各成员DPS/伤害/占比 + 技能详情

## 十四、已知局限

- 装备副属性已解析 `str/agi/int/wil/atk%/hp%/def%/critRate/critDamage/damageBonus`，但游戏实际词条可能更多
- 排轴引擎的冷却/能量消耗为估算值(默认 普攻0/战技20/连携0/终结技80)，缺少游戏内精确数值
- 无用户认证系统 (单机使用)
- 无 Excel 导入功能
