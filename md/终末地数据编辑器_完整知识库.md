## 1. 核心数据模型

### 1.1 角色

| 字段 | 说明 | 示例 |
|------|------|------|
| 角色ID | 唯一标识 | `chr_0005_chen` |
| 角色名称 | | `陈千语` |
| 稀有度 | 4~6 星 | `6` |
| 等级 | 1~90 | `90` |
| 基础生命值 | 从 AKEDatabase growth 数组取值 | |
| 基础攻击力 | 同上 | |

### 1.2 武器

| 字段 | 说明 |
|------|------|
| 武器ID | 唯一标识 |
| 类型 | 单手剑/双手剑/长柄武器/手铳/施术单元 (英文存储：sword/claymore/lance/pistol/caster_unit) |
| 稀有度 | 3~6 星 / 潜能 0~5 |
| 等级 | 1~90 |
| 基础攻击力 | 按稀有度档位线性插值（每级一个值） |
| 词条1 | 能力值（力量/敏捷/智识/意志），规格 小/中/大，等级 1~9 |
| 词条2 | 百分比加成（属性伤害/攻击力%等），等级 1~9 |
| 词条3 | 特殊效果（强攻/压制等），含 effect1/2/3 分项，等级 1~9 |

**6 星武器基础攻击力分档**：共 6 档，1 级依次 49/50/50/51/51/52，90 级依次 485/490/495/500/505/510。

**词条升阶规则**：

| 武器等级 | 词条1上限 | 词条2上限 |
|----------|----------|----------|
| 1~20 | Lv.3 | Lv.3 |
| 20~40 | Lv.5 | Lv.4 |
| 40~60 | Lv.6 | Lv.6 |
| 60~80 | Lv.8 | Lv.7 |
| 80~90 | Lv.9 | Lv.9 |

**词条3等级 = 潜能 + 4**（0潜→Lv.4, ..., 5潜→Lv.9）

**词条数值规则**：等级 1~8 提升幅度为 1 倍，8→9 提升幅度为 2 倍。

### 1.3 装备

**部位**：护甲(armor)、护手(glove)、配件(accessory ×2)

| 字段 | 说明 |
|------|------|
| 装备ID | 唯一标识 |
| 等级 | 10/20/28/36/50/70 |
| 基础防御力 | 70级：护甲 56，护手 42，配件 21 |
| 套装名称 | 独立装备也有套装名 |

各技能类型伤害加成、对失衡目标伤害加成、全伤害减免

### 1.5 增益

| 字段 | 说明 |
|------|------|
| 增益来源 | 角色/武器/装备/其他 |
| 增益类型(gainType) | 常驻(permanent)/限定(limited) |
| 触发条件 | 限定增益专用 |
| 持续时间 | 秒 |
| 效果大类(effectCategory) | |
| 效果类型(effectType) | 见下文枚举 |
| 效果数值(effectValue) | |
| 数值类型(valueType) | 绝对值(absolute)/百分比(percentage) |
| 叠加方式(stackRule) | 同名加算(add_same)/独立乘区(multi_diff) |
| 目标范围(targetScope) | 自身(self)/全队(team)/指定角色(character) |

**增益效果类型完整枚举**：

- **基础属性**：基础攻击力固定值/%、生命值%、防御力%
- **能力值**：力量/敏捷/智识/意志（固定值）、主能力/副能力/全能力/%
- **伤害加成**：各属性伤害加成、法术加成
- **技能加成**：普攻/战技/连携技/终结技/所有技能/失衡期间加成
- **特殊加成**：增幅（各属性）、脆弱、易伤、抗性降低、失衡易伤
- **连击**：增强战技和终结技，非线性叠加，持续 5 秒
- **源石技艺强度**：增强法术异常/物理异常伤害和效果
- **暴击**：额外暴击率、额外暴击伤害
- **其他**：技能倍率加成、元素精通加成、等级系数加成、全属性伤害减免、治疗效率提升、终结技充能效率

## 2. 配装系统

**单角色配装结构**：

```
角色（1个）
├── 武器（1把，类型需匹配角色可用武器类型）
├── 护甲（1件）
├── 护手（1件）
├── 配件一（1件）
└── 配件二（1件）
```

**面板计算输入**（calcFinalStats）：

| 输入来源 | 使用的字段 |
|---------|-----------|
| 角色配置 | baseAtk, baseHp, baseStr/Agi/Int/Wil, mainAttr, subAttr, trustLevel |
| 武器配置 | baseAtk, affix1Type, affix1Value |
| 装备配置 | str/agi/int/wil 固定值, atkPercent, hpPercent, defPercent, critRate, critDamage, damageBonus, artsMastery, energyRecharge |

**面板输出**（FinalStats）：

| 字段 | 来源 |
|------|------|
| attack | calcAttack(基础+武器+百分比+能力值加成) |
| hp | calcHp(基础×百分比) |
| str/agi/int/wil | calcStat(基础+信赖+武器匹配+装备) |
| attrBonus | floor(主)×0.005 + floor(副)×0.002 |
| defPercent | 装备累加 |
| critRate / critDamage / damageBonus | 装备累加 |
| artsMastery | 装备累加（源石技艺强度） |
| energyRecharge | 装备累加（充能效率） |
| physicalResist | floor(agi)>0 ? 100-100/(0.001×floor(agi)+1) : 0 |
| magicResist | floor(int)>0 ? 100-100/(0.001×floor(int)+1) : 0 |

**套装检测**：统计同名套装件数，≥2 件激活。

**方案管理**：保存方案(角色+武器+4装备ID)/加载/导出Excel(含15乘区明细)。

## 3. 四人配队系统

```
队伍（4个不同角色）
├── 角色A + 配装方案(buildA) + 技能列表
├── 角色B + 配装方案(buildB) + 技能列表
├── 角色C + ...
└── 角色D + ...
```

- 四个位置无区别，不可重复角色
- 部分增益为全队类型（gain.targetScope=team）
- 伤害输出：每角色 + 占比 + 总计

## 4. 战斗机制详解

### 4.1 技力机制

| 属性 | 规则 |
|------|------|
| 类型 | 全队共用资源 |
| 上限/起始 | 300 / 200 |
| 回复 | 8 技力/秒 |
| 消耗 | 所有战技统一消耗 100 技力 |
| 脱战回复 | 75 点/秒（降至 2 格 200 点） |
| 脱战降低 | 40 点/秒 |
| 完全脱战 | 需 3 秒 |

**技力获取方式**：
- 自动回复（接战 8/秒）
- 主控重击命中（数值取决于干员）
- 处决攻击（普通 25 / 进阶 35 / 精英 50 / 领袖 100）
- 技能返还（不触发能量获取）
- 极限闪避（约 7.5 点，暂停回复 0.5 秒）

### 4.2 终结技能量机制

| 属性 | 规则 |
|------|------|
| 类型 | 各角色独立 |
| 上限 | 各干员不同（在技能界面查阅） |
| 充能 | 每消耗 1 点实际技力获得 0.065 能量 |
| 连携技 | 释放者自身获得能量（默认 10 点） |
| 充能效率 | 最终能量 = 基础恢复 × 终结技充能效率（装备词条） |

### 4.3 法术附着与法术异常/爆发

法术附着持续 20 秒，可叠加至多 4 层，重复添加刷新。

| 反应 | 触发 | 效果 |
|------|------|------|
| **导电** | 其他附着 + 电磁 | 电磁伤害 + 法术伤害+12%~24%（随异常等级） |
| **腐蚀** | 其他附着 + 自然 | 自然伤害 + 降低抗性 3.6→24 点 |
| **燃烧** | 其他附着 + 灼热 | 灼热伤害 + 持续伤害(12%倍率/秒) |
| **冻结** | 其他附着 + 寒冷 | 寒冷伤害 + 弱小敌人无法行动(6~9秒) |
| **碎冰** | 冻结 + 破防/物理异常 | 物理伤害(120%×(1+等级)) |
| **法术爆发** | 同属性叠加 | 对应属性伤害(160%倍率，不消耗附着) |

**异常等级**：等于触发物理异常或法术异常时消耗的破防/法术附着层数（最高4级），等级越高效果越强。

### 4.4 物理异常

首次受物理异常时进入破防状态（持续 20 秒，最多 4 层）。破防不属于物理异常。

| 反应 | 触发 | 效果 |
|------|------|------|
| **倒地** | 破防 + 倒地技能 | +1 破防，120%伤害，10 失衡 |
| **击飞** | 破防 + 击飞技能 | +1 破防，120%伤害，10 失衡 |
| **碎甲** | 破防 + 碎甲技能 | 消耗所有破防，50%×(1+等级)伤害 + 物理易伤12%~24% |
| **猛击** | 破防 + 猛击技能 | 消耗所有破防，150%×(1+等级)大量伤害 |

### 4.5 异常等级系数

| 伤害类型 | 公式 | 90级系数 |
|----------|------|---------|
| 法术异常/爆发 | `1 + (等级-1)/196` | 1.454 |
| 物理异常 | `1 + (等级-1)/392` | 1.227 |

### 4.6 连击机制

特殊 buff，持续 5 秒，可叠加（最多 4 层，非线性衰减）。

| 层数 | 战技提升 | 终结技提升 |
|------|---------|----------|
| 1 | 30% | 20% |
| 2 | 45% | 30% |
| 3 | 60% | 40% |
| 4 | 75% | 50% |

当前游戏中仅黎风的连携技和秋栗解锁天赋后的终结技可提供连击效果。

### 4.7 敌人抗性档位

| 档位 | 数值 | 说明 |
|------|------|------|
| D | 0 | 默认档位 |
| C | 20 | 大部分敌人 (个别为 30/35) |
| B | 50 | 仅碾骨清道夫/碾骨焰术师的灼热抗性 |

敌人基础防御力固定为 100，不随等级提升。

## 5. 计算公式（完整版）

### 5.1 面板属性

**攻击力**（已验证 ✅）：
```
最终攻击力 = [(干员基础攻击力 + 武器基础攻击力) × (1 + 百分比加成) + 固定加成]
           × (1 + INT(主能力) × 0.005 + INT(副能力) × 0.002)
```

> 验证案例：管理员90级配装（宏愿+点剑重装甲+轻超域护手+点剑火石×2）
> - 基础+武器 = 319+500 = 819, 百分比 = 0.39
> - 主能力(敏捷)=635, 副能力(力量)=307
> - 能力值加成 = INT(635)×0.005 + INT(307)×0.002 = 3.175 + 0.614 = 3.789
> - 最终 = 819 × 1.39 × 4.789 = **5452** ✅

**四维能力值**：
```
能力值 = (基础 + 信赖加成 + 武器词条匹配值 + 装备值) × (1 + 百分比加成)
信赖加成: Lv.1=10, Lv.2=25, Lv.3=40, Lv.4=60
```

**属性加成**：
```
属性加成 = INT(主能力) × 0.005 + INT(副能力) × 0.002
```

**生命值**：
```
最终生命值 = 基础生命值 × (1 + 生命值%累加) + 固定生命值
```

**物理/法术抗性**（验证 ✅）：
```
物理抗性 = floor(敏捷) > 0 ? 100 - 100 / (0.001 × floor(敏捷) + 1) : 0
法术抗性 = floor(智识) > 0 ? 100 - 100 / (0.001 × floor(智识) + 1) : 0
```

### 5.2 增益叠加规则

1. **同名增益先加算**：攻击力+20% + +10% = +30%
2. **先固定值后百分比**
3. **不同名增益独立乘区**

### 5.3 技能伤害公式（15 乘区）

```
最终伤害 = 基础 × 暴击 × 增伤 × 减伤 × 增幅 × 虚弱 × 庇护
         × 脆弱 × 易伤 × 防御 × 失衡 × 抗性 × 非受控 × 连击 × 特殊
```

| # | 乘区 | 公式 | 说明 |
|---|------|------|------|
| 1 | **基础** | `攻击力 × 倍率 + 基础伤害提升` | 大多数情况基于攻击力 |
| 2 | **暴击(期望)** | `1 + 暴击率 × 暴击伤害` | 基础暴击率5%，基础爆伤50% |
| 3 | **增伤** | `1 + 所有伤害类型加成` | 含属性/技能类型/失衡加成 |
| 4 | **减伤** | `Π(1 - 伤害减免)` | 乘算，各伤害减免独立 |
| 5 | **增幅** | `1 + Σ增幅` | 特定属性伤害提高，加算 |
| 6 | **虚弱** | `Π(1 - 虚弱)` | 目标造成伤害降低，乘算 |
| 7 | **庇护** | `1 - max(庇护)` | 受到伤害降低，取最大值 |
| 8 | **脆弱** | `1 + Σ脆弱` | 目标受到特定属性伤害提高 |
| 9 | **易伤** | `1 + Σ易伤` | 未标注为脆弱的效果 |
| 10 | **防御** | `真伤?1 : 100/(防御+100)` | 干员基础防御0，敌人基础防御100 |
| 11 | **失衡** | `失衡?1.3 : 1` | 敌人失衡时受到伤害+30% |
| 12 | **抗性** | `1 - 抗性/100 + 穿透/100` | 物抗源自敏捷，法抗源自智识 |
| 13 | **非受控** | `1 - 非主控减伤` | 仅敌人技能对非主控生效 |
| 14 | **连击** | `1 + 连击增伤` | 连携技自带0.3 |
| 15 | **特殊** | `独立乘数` | 独立于以上所有 |

### 5.4 法术异常/爆发伤害

```
异常伤害 = 倍率 × (1 + 异常等级) × 等级系数区 × (1 + 源石技艺强度/100)
```

| 反应 | 倍率 | 等级影响 |
|------|------|---------|
| 导电/腐蚀/燃烧/冻结 | 80% | ×(1+等级) |
| 燃烧持续伤害 | 12% | ×(1+等级) |
| 碎冰 | 120% | ×(1+等级) |
| 法术爆发 | 160% | 不随等级变化 |

**等级系数区（法术）**：`1 + (等级-1)/196`，90 级 = 1.454

### 5.5 物理异常伤害

```
异常伤害 = 倍率 × 层数乘数 × 等级系数区 × (1 + 源石技艺强度/100)
```

| 反应 | 倍率 | 层数乘数 |
|------|------|---------|
| 击飞/倒地 | 120% | 1（不消耗破防） |
| 碎甲 | 50% | 层数+1（消耗所有破防） |
| 猛击 | 150% | 层数+1（消耗所有破防） |

**等级系数区（物理）**：`1 + (等级-1)/392`，90 级 = 1.227

### 5.6 源石技艺强度增强

```
附带效果增强 = 2 × 源石技艺强度 / (源石技艺强度 + 300)
```

每点源石技艺强度：
- 猛击/燃烧/冻结/碎冰/法术爆发：伤害 +1%
- 碎甲/导电/腐蚀：伤害 +1%，附带效果增强（与原始效果乘算）
- 击飞/倒地：伤害 +1%，失衡值 +0.5%

### 5.7 处决伤害

```
处决伤害 = 常规伤害乘区 × 处决承伤系数
处决承伤系数: 普通1.0 / 进阶1.25 / 精英1.5 / 领袖1.75
```

属于常规伤害，受普通攻击加成影响。

### 5.8 治疗公式

```
治疗量 = 基础治疗区 × 治疗效率区 × 独立治疗效果区

基础治疗区 = 治疗基础值 + 治疗倍率 × 对应属性
治疗效率区 = 1 + 治疗方治疗效率 + 受治疗方受治疗效率
独立治疗效果区 = 1 + 独立治疗效果提升
```

## 6. 排轴模拟

### 6.1 单角色模拟

**输入**：
- 配装方案 → 完整面板(FinalStats)
- 技能列表（含等级倍率）
- 循环序列（用户编排的技能施放顺序）
- 目标参数：防御/抗性/暴击率/爆伤/增伤/数量
- 进阶参数：失衡/减伤/增幅/脆弱/易伤/连击/特殊乘数
- **技能动作参数**：优先从 skill_action 表读取 castTime/techCost/chainCd/ultimateCd

**引擎流程**：
```
循环直到模拟时长耗尽:
  1. 自动攻击检查（每1.5s，+5能量）
  2. 取下一技能（循环序列）
  3. 冷却就绪 && 能量满足 → 施放(消耗能量，走冷却，结算伤害)
  4. 否则等待 0.1s
```

**输出**：
- DPS / 总伤害 / 总施放次数
- 技能伤害占比表
- 时间线事件流（前30秒）

**输出**：

- 各成员总伤害/DPS/占比
- 每成员技能伤害详情

### 6.4 分类驱动伤害计算（v2 引擎）

新增引擎模块（与原有 15 乘区 `calcDamage` 并存），参考编队总伤计算器设计。

**乘区分类定义**（`damageCategories.ts`）：

```typescript
DAMAGE_CATEGORIES = [
  { key: 'DMG_Dealt',      label: '增伤' },
  { key: 'DMG_Taken',      label: '易伤' },
  { key: 'Susceptibility', label: '脆弱' },
  { key: 'Arts_Amp',       label: '增幅' },
  { key: 'Resistance',     label: '抗性' },
  { key: 'Link',           label: '连击' },
  { key: 'Staggered',      label: '失衡' },
  { key: 'Finisher',       label: '处决' },
]
```

**计算流程**：

```
calcDamageByCategories(baseDamage, activeBuffs, categories, context)
  → 遍历 buff.effects[]，按 category 分组，累加 rawTotal
  → 遍历 buff.metas[]，在 rawTotal 上乘算 meta 元乘数 → finalTotal
  → 每分类 multiplier = 1 + finalTotal
  → finalDamage = baseDamage × Π(allCategoryMultipliers)
```

**Buff 效果解析**（`effectResolver.ts`，从参考项目移植）：

| 模式 | 数据格式 | 公式 |
|------|---------|------|
| 固定值 | `{ value: 0.2 }` | `value` |
| 线性缩放 | `{ scaleStat, scaleRatio, scaleCap? }` | `min(stat × ratio, cap)` |
| 分段线性曲线 | `{ scaleStat, scaleCurve }` | `piecewiseLinear(stat, curve)` |
| 饱和缩放 | `{ value, saturationScale: { stat, x, y, z } }` | `value × (x + y×stat/(z+stat))` |

**条件系统**：

Buff 效果可按 `skillType`（普攻/战技/连携/终结）和 `element`（物理/灼热/寒冷/电磁/自然）过滤，命中特定技能时仅适用特定 Buff。

**增益→乘区映射**（`stats.ts`）：

```typescript
GAIN_CATEGORY_TO_DAMAGE_CAT = {
  '增伤': 'DMG_Dealt', '易伤': 'DMG_Taken', '脆弱': 'Susceptibility',
  '增幅': 'Arts_Amp', '抗性': 'Resistance', '连击': 'Link',
  '失衡': 'Staggered', '处决': 'Finisher',
}
```

### 6.5 三种模拟引擎

| 引擎 | 文件 | 用途 | 输入 |
|------|------|------|------|
| **时间线模拟** | `timeSimEngine.ts` | 按时间轴事件驱动（技能开始/结束/伤害判定帧） | `Track[]`, `SystemConstants` |
| **团队循环模拟** | `teamEngine.ts` | 按旋转队列循环（冷却/能量管理） | `TeamMemberConfig[]`, `SimulationConfig` |
| **失衡模拟** | `staggerEngine.ts` | 仅追踪失衡/SP 曲线（用于 CurvePanel 渲染） | `Track[]`, `TimelineEnemy[]` |

**时间线伤害完整演算** (`runTimelineSimulationWithDamage`)：在每个 damage_tick 事件中调用 `calcDamageByCategories`，同时追踪连击层数、Buff 快照、敌我状态，输出 `DamageEvent[]` 含完整乘区拆解。

**循环↔时间线互转** (`rotationConverter.ts`)：
- `rotationToActions()` — 将 TeamSimulator 的旋转循环展开为时间线动作序列
- `actionsToRotation()` — 从时间线动作中检测循环模式，提取最小循环单元
- `detectCyclePattern()` — 通过自相关检测自动识别重复序列

### 7.1 枚举值映射（前后端统一）
