## 1. 核心数据模型

### 1.1 角色

| 字段 | 说明 | 示例 |
|------|------|------|
| 角色ID | 唯一标识 | `chr_0005_chen` |
| 角色名称 | | `陈千语` |
| 稀有度 | 4~6 星 | `6` |
| 等级 | 1~90 | `90` |
| 基础生命值 | 从 AKEDatabase growth 数组取值 | |
| 基础攻击力 | 同上 | |
| 基础力量/敏捷/智识/意志 | DECIMAL(10,4) | |
| 主能力 | 力量/敏捷/智识/意志 | `力量` |
| 副能力 | 同上 | `敏捷` |
| 职业 | 突击/近卫/术士/重装/先锋/辅助 | `近卫` |
| 属性 | 灼热/寒冷/电磁/自然/物理 | `物理` |
| 可用武器类型 | 与武器 type 统一 | `单手剑` |
| 潜能 | 0~5 | `3` |
| 信赖天赋等级 | 1~4 | `4` |

**信赖天赋累计加成**：

| 等级 | 能力加成 |
|------|---------|
| 1 | +10 |
| 2 | +15（累计 25） |
| 3 | +15（累计 40） |
| 4 | +20（累计 60） |

### 1.2 武器

| 字段 | 说明 |
|------|------|
| 武器ID | 唯一标识 |
| 类型 | 单手剑/双手剑/长柄武器/手铳/施术单元 |
| 稀有度 | 3~6 星 / 潜能 0~5 |
| 等级 | 1~90 |
| 基础攻击力 | 按稀有度档位线性插值 |
| 词条1 | 能力值（力量/敏捷/智识/意志），分小/中/大，等级 1~9 |
| 词条2 | 百分比加成（属性伤害/攻击力%等），等级 1~9 |
| 词条3 | 特殊效果（强攻/压制等），等级 1~9 |

**6 星武器基础攻击力分档**：共 6 档，1 级依次 49/50/50/51/51/52，90 级依次 485/490/495/500/505/510。

**词条升阶规则**：

| 武器等级 | 词条1上限 | 词条2上限 |
|----------|----------|----------|
| 1~20 | Lv.3 | Lv.3 |
| 20~40 | Lv.5 | Lv.4 |
| 40~60 | Lv.6 | Lv.6 |
| 60~80 | Lv.8 | Lv.7 |
| 80~90 | Lv.9 | Lv.9 |

**词条3等级 = 潜能 + 4**（0潜→Lv.4, ..., 5潜→Lv.9）

**词条数值规则**：等级 1~8 提升幅度为 1 倍，8→9 提升幅度为 2 倍。

### 1.3 装备

**部位**：护甲、护手、配件（可装备 2 件）

| 字段 | 说明 |
|------|------|
| 装备ID | 唯一标识 |
| 等级 | 10/20/28/36/50/70 |
| 基础防御力 | 70级：护甲 56，护手 42，配件 21 |
| 套装名称 | 独立装备也有套装名 |
| 属性一/二 | 能力值 + 0~3 精锻 |
| 属性三 | 百分比属性 + 0~3 精锻 |
| 套装效果一 | 常驻效果 |
| 套装效果二 | 限定效果 |

**属性三完整枚举**：攻击力、生命值、攻击力%/生命值%、暴击率、源石技艺强度、治疗效率加成、各属性伤害加成、各技能类型伤害加成、对失衡目标伤害加成、全伤害减免、终结技充能效率、主能力%、副能力%

**精锻数值示例（70级）**：

| 属性类型 | 精锻0 | 精锻1 | 精锻2 | 精锻3 |
|----------|-------|-------|-------|-------|
| 能力值（护甲） | 115 | 126 | 138 | 149 |
| 能力值（护手） | 65 | 71 | 78 | 84 |
| 能力值（配件） | 32 | 35 | 38 | 41 |
| 百分比加成 | 14.4% | 15.84% | 17.28% | 18.72% |

### 1.4 技能

| 字段 | 说明 |
|------|------|
| 技能ID | 唯一标识 |
| 角色ID | 关联角色 |
| 技能类型 | 普通攻击/战技/连携技/终结技/天赋一/天赋二/其他类型 |
| 等级 | 1~12 |
| 伤害类型 | 灼热/寒冷/电磁/自然/物理/超域/真实/其他 |
| 伤害倍率 | 每级独立曲线 |
| 技能描述 | |

### 1.5 增益

| 字段 | 说明 |
|------|------|
| 增益来源 | 角色/武器/装备/其他 |
| 增益类型 | 常驻/限定 |
| 触发条件 | 限定增益专用 |
| 持续时间 | 秒 |
| 增益效果类型 | 见下文 |
| 叠加方式 | 同名加算/独立乘区 |
| 目标范围 | 自身/全队/指定角色 |

**增益效果类型完整枚举**：

- **基础属性**：基础攻击力固定值/%、生命值%、防御力%
- **能力值**：力量/敏捷/智识/意志（固定值）、主能力/副能力/全能力/%
- **伤害加成**：各属性伤害加成、法术加成
- **技能加成**：普攻/战技/连携技/终结技/所有技能/失衡期间加成
- **特殊加成**：增幅（各属性）、脆弱、易伤、抗性降低、失衡易伤
- **连击**：增强战技和终结技，非线性叠加，持续 5 秒
- **源石技艺强度**：增强法术异常/物理异常伤害和效果
- **暴击**：额外暴击率、额外暴击伤害
- **其他**：技能倍率加成、元素精通加成、等级系数加成、全属性伤害减免、治疗效率提升、终结技充能效率

## 2. 配装系统

**单角色配装结构**：

```
角色（1个）
├── 武器（1把，类型需匹配角色可用武器类型）
├── 护甲（1件）
├── 护手（1件）
├── 配件一（1件）
└── 配件二（1件）
```

- **套装检测**：统计同名套装件数，≥2 件激活
- **实时面板**：攻击/HP/四维/防御%/暴击%/爆伤%/增伤%/属性加成
- **方案管理**：保存/加载/导出Excel(含乘区明细)/导入

## 3. 四人配队系统

```
队伍（4个不同角色）
├── 角色A + 配装方案 + 技能列表
├── 角色B + 配装方案 + 技能列表
├── 角色C + ...
└── 角色D + ...
```

- 四个位置无区别，不可重复角色
- 部分增益为全队类型
- 伤害输出：每角色 + 占比 + 总计

## 4. 战斗机制详解

### 4.1 技力机制

| 属性 | 规则 |
|------|------|
| 类型 | 全队共用资源 |
| 上限/起始 | 300 / 200 |
| 回复 | 8 技力/秒 |
| 消耗 | 所有战技统一消耗 100 技力 |

### 4.2 终结技能量机制

| 属性 | 规则 |
|------|------|
| 类型 | 各角色独立 |
| 充能 | 每消耗 1 点实际技力获得 0.065 能量 |
| 充能效率 | 最终能量 = 任意来源能量 × 终结技充能效率 |

### 4.3 法术附着与法术异常/爆发

法术附着持续 20 秒，可叠加至多 4 层，重复添加刷新。

| 反应 | 触发 | 效果 |
|------|------|------|
| **导电** | 其他附着 + 电磁 | 电磁伤害 + 法术伤害+12%~24% |
| **腐蚀** | 其他附着 + 自然 | 自然伤害 + 降低抗性 3.6→24 点 |
| **燃烧** | 其他附着 + 灼热 | 灼热伤害 + 持续伤害 |
| **冻结** | 其他附着 + 寒冷 | 寒冷伤害 + 弱小敌人无法行动 |
| **碎冰** | 冻结 + 破防/物理异常 | 物理伤害 |
| **法术爆发** | 同属性叠加 | 对应属性伤害 |

**异常等级**：基于源石技艺强度计算（<100=1级, <200=2级, <300=3级, 300+=4级）。

### 4.4 物理异常

首次受物理异常时进入破防状态（持续 20 秒，最多 4 层）。

| 反应 | 触发 | 效果 |
|------|------|------|
| **倒地** | 破防 + 倒地技能 | +1 破防，伤害，10 失衡 |
| **击飞** | 破防 + 击飞技能 | +1 破防，伤害，10 失衡 |
| **碎甲** | 破防 + 碎甲技能 | 消耗破防，伤害 + 物理易伤 |
| **猛击** | 破防 + 猛击技能 | 消耗破防，大量伤害 |

### 4.5 异常等级系数

| 伤害类型 | 公式 | 90级系数 |
|----------|------|---------|
| 法术异常/爆发 | `1 + (等级-1)/196` | 1.454 |
| 物理异常 | `1 + (等级-1)/392` | 1.227 |

### 4.6 连击机制

特殊 buff，持续 5 秒，可叠加（最多 4 层，非线性）。

| 层数 | 战技提升 | 终结技提升 |
|------|---------|----------|
| 1 | 30% | 20% |
| 2 | 45% | 30% |
| 3 | 60% | 40% |
| 4 | 75% | 50% |

## 5. 计算公式（完整版）

### 5.1 面板属性

**攻击力**：
```
最终攻击力 = [(基础攻击力 + 武器攻击力) × (1 + 百分比加成) + 固定加成]
           × (1 + 主能力×0.005 + 副能力×0.002)
```

**能力值**：
```
最终能力值 = (基础值 + 信赖 + 武器词条 + 装备) × (1 + 全能力%累加)
```

**生命值**：
```
最终生命值 = 基础生命值 × (1 + 生命值%累加) + 固定生命值
```

### 5.2 增益叠加规则

1. **同名增益先加算**：攻击力+20% + +10% = +30%
2. **先固定值后百分比**
3. **不同名增益独立乘区**

### 5.3 技能伤害公式（15 乘区）

```
最终伤害 = 基础 × 暴击 × 增伤 × 减伤 × 增幅 × 虚弱 × 庇护
         × 脆弱 × 易伤 × 防御 × 失衡 × 抗性 × 非受控 × 连击 × 特殊
```

| 乘区 | 公式 |
|------|------|
| **基础** | `倍率 × 攻击力 + 基础伤害提升` |
| **暴击（期望）** | `1 + 暴击率 × 暴击伤害` |
| **增伤** | `1 + 所有伤害类型加成` |
| **减伤** | `Π(1 - 伤害减免)` |
| **增幅** | `1 + Σ增幅` |
| **虚弱** | `Π(1 - 虚弱)` |
| **庇护** | `1 - max(庇护)` |
| **脆弱** | `1 + Σ脆弱` |
| **易伤** | `1 + Σ易伤` |
| **防御** | 真伤=1；其他=`1 - 防御/(防御+100)` |
| **失衡** | 失衡时=1.3，其他=1 |
| **抗性** | `1 - 抗性/100 + 无视抗性/100` |
| **非受控** | 非主控角色在场上时生效 |
| **连击** | `1 + 连击增伤` |
| **特殊** | 独立于以上 |

### 5.4 法术异常/爆发伤害

```
异常伤害 = 倍率 × (1 + 异常等级) × 等级系数区 × (1 + 源石技艺强度/100)
```

| 反应 | 倍率 |
|------|------|
| 导电/腐蚀/燃烧/冻结 | 80% |
| 碎冰 | 120% |
| 法术爆发 | 160% |

### 5.5 物理异常伤害

```
异常伤害 = 倍率 × 层数乘数 × 等级系数区 × (1 + 源石技艺强度/100)
```

| 反应 | 倍率 | 层数乘数 |
|------|------|---------|
| 击飞/倒地 | 120% | 1 |
| 碎甲 | 50% | 层数+1 |
| 猛击 | 150% | 层数+1 |

### 5.6 源石技艺强度增强

```
附带效果增强 = 2 × 源石技艺强度 / (源石技艺强度 + 300)
```

每点源石技艺强度：
- 猛击/燃烧/冻结/碎冰/法术爆发：伤害 +1%
- 碎甲/导电/腐蚀：伤害 +1%，附带效果增强
- 击飞/倒地：伤害 +1%，失衡值 +0.5%

## 7. 数据库设计规范

### 枚举值

| 枚举 | 值 |
|------|-----|
| 武器类型 | 单手剑/双手剑/长柄武器/手铳/施术单元 |
| 技能类型 | 普通攻击/战技/连携技/终结技/天赋一/天赋二/其他 |
| 伤害类型 | 灼热/寒冷/电磁/自然/物理/超域/真实/其他 |
| 职业 | 突击/近卫/术士/重装/先锋/辅助 |
| 能力 | 力量/敏捷/智识/意志 |
| 装备部位 | 护甲/护手/配件 |
| 增益类型 | 常驻/限定 |
| 增益叠加 | 同名加算/独立乘区 |

### 核心表

| 表名 | 说明 |
|------|------|
| `character` | 角色基础属性、职业、武器类型、信赖 |
| `weapon` | 武器基础攻击、3 词条 |
| `equipment` | 装备部位、防御、3 属性(4精炼)、套装效果 |
| `gain` | 增益详情 |
| `skill` | 技能名称/类型/伤害类型 |
| `skill_level` | 等级 1-12 倍率 |
| `skill_action` | 技能动作参数 (v2.0+) |
| `build` | 配装方案 (角色/武器/4装备) |
| `team` | 配队 (4角色+4配装) |

所有表均预留 `reserve1`/`reserve2` 字段和 `created_at`/`updated_at` 时间戳。
