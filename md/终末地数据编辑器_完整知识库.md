## 1. 项目概述

### 1.1 背景与痛点

《终末地》玩家需要计算角色在不同配装下的伤害表现。当前使用 Excel 手动计算，存在：
- 公式复杂易出错
- 数据更新不便
- 无法直观对比不同配装
- 配队和排轴模拟困难
- 分享困难

### 1.2 项目目标

开发 Web 端数据编辑器，帮助玩家：
- 可视化编辑角色、武器、装备数据
- 快速配置单角色配装方案
- 构建四人配队，编辑战斗时间轴
- 模拟技能释放顺序、元素反应、异常触发
- 实时计算技能伤害、总伤害、DPS、增益覆盖
- 支持 Excel 导入/导出、方案保存与分享

### 1.3 用户角色

| 角色 | 权限 |
|------|------|
| 普通玩家 | 浏览数据、创建/编辑配装方案、构建配队、编辑排轴、保存到云端、导出 Excel/图片、生成分享码 |
| 高级玩家/数据贡献者 | 可导入他人数据、合并到数据库、填写角色技能动作时间参数 |
| 管理员 | 管理基础数据（角色/武器/装备/技能库） |

## 3. 配装系统

### 3.1 单角色配装结构

```
角色（1个）
├── 武器（1把，类型需匹配角色可用武器类型）
├── 护甲（1件）
├── 护手（1件）
├── 配件一（1件）
└── 配件二（1件）
```

### 3.2 规则

- **套装检测**：统计同名套装件数，≥3 件激活套装效果
- **方案管理**：保存/加载/对比/分享（分享码）/导出（Excel/JSON/截图）/导入（Excel/JSON，支持覆盖/合并）

## 4. 四人配队系统

### 4.1 配队结构

```
队伍（4个不同角色）
├── 角色A + 配装方案 + 技能列表
├── 角色B + 配装方案 + 技能列表
├── 角色C + ...
└── 角色D + ...
```

- 四个位置无区别
- 队伍中不可有重复角色
- 部分增益为全队类型

### 4.2 配队伤害计算

- 全队增益对所有 4 个角色生效
- 各自角色的配装独立计算
- 输出：每个角色伤害 + 占队伍比例 + 总计

## 5. 战斗机制详解

### 5.1 技力机制

| 属性 | 规则 |
|------|------|
| 类型 | 全队共用资源 |
| 上限/起始 | 300 / 200 |
| 回复 | 8 技力/秒 |
| 消耗 | 所有战技统一消耗 100 技力 |
| 返还 | 部分角色战技有技力返还（不给终结技能量） |
| 恢复 | 先锋角色技能有技力恢复 |

### 5.2 终结技能量机制

| 属性 | 规则 |
|------|------|
| 类型 | 各角色独立 |
| 充能 | 每消耗 1 点实际技力获得 0.065 能量 |
| 溢出 | 满能量后继续获取会浪费 |
| 充能效率 | 最终能量 = 任意来源能量 × 终结技充能效率 |

**特殊充能示例**：
- 角色A：连携技命中回复 10 能量
- 角色B：连携技命中回复 10 + 击碎结晶再回复 15
- 角色C：战技消耗寒冷附着，每层额外回复 30

### 5.3 法术附着与法术异常/爆发

**法术附着**：持续 20 秒，可叠加至多 4 层，重复添加刷新持续时间。

| 反应 | 触发条件 | 效果 |
|------|----------|------|
| **导电** | 其他附着 + 电磁 | 消耗所有层数→电磁伤害。敌人法术伤害+12%~24%，持续 12~30 秒 |
| **腐蚀** | 其他附着 + 自然 | 消耗所有层数→自然伤害。初始降低 3.6~7.2 点全属性抗性，每秒再降 0.84~1.68，至多降 12~24 点，持续 15 秒 |
| **燃烧** | 其他附着 + 灼热 | 消耗所有层数→灼热伤害 + 每秒持续伤害，持续 10 秒 |
| **冻结** | 其他附着 + 寒冷 | 消耗所有层数→寒冷伤害。弱小敌人无法行动，持续 6~9 秒 |
| **碎冰** | 冻结 + 破防/物理异常 | 消耗冻结→物理伤害（属于法术异常） |
| **法术爆发** | 同属性附着叠加 | 叠加 1 层附着（最多 4 层），造成对应属性伤害 |

**异常等级**：基于触发角色的源石技艺强度计算。

### 5.4 物理异常

**破防**：首次受物理异常时进入破防状态（持续 20 秒），可叠加层数（至多 4 层），刷新持续时间。破防本身不属于物理异常。

| 反应 | 触发条件 | 效果 |
|------|----------|------|
| **倒地** | 破防 + 倒地技能 | 叠加 1 层破防，物理伤害，10 点失衡值 |
| **击飞** | 破防 + 击飞技能 | 叠加 1 层破防，物理伤害，10 点失衡值 |
| **碎甲** | 破防 + 碎甲技能 | 消耗所有破防层数，物理伤害，物理易伤+12%~24%，持续 12~30 秒 |
| **猛击** | 破防 + 猛击技能 | 消耗所有破防层数，大量物理伤害 |

### 5.5 异常等级与等级系数

| 伤害类型 | 等级系数公式 | 90级系数 |
|----------|-------------|----------|
| 法术异常/法术爆发 | `1 + (等级 - 1) / 196` | 1.454 |
| 物理异常 | `1 + (等级 - 1) / 392` | 1.227 |
| 其他伤害 | 1 | 1 |

### 5.6 连击机制

- 特殊 buff，持续 5 秒
- 目前仅秋栗（终结技）、黎风（连携技）可提供
- 任意角色使用战技/终结技消耗连击 buff
- 同类效果可叠加（最多 4 层），非线性叠加

| 层数 | 战技伤害提升 | 终结技伤害提升 |
|------|-------------|---------------|
| 1 | 30% | 20% |
| 2 | 45% | 30% |
| 3 | 60% | 40% |
| 4 | 75% | 50% |

## 6. 计算公式（完整版）

### 6.1 角色面板属性计算

**攻击力**：
```
最终攻击力 = [(角色基础攻击力 + 武器基础攻击力) × (1 + 百分比加成累加) + 固定数值加成]
           × (1 + 能力值加成)
```
- 能力值加成 = `主能力 × 0.005 + 副能力 × 0.002`
- 四维属性在计算中使用其整数部分

**能力值**：
```
最终能力值 = (角色基础值 + 信赖天赋加成 + 武器词条能力值 + 装备能力值累加)
           × (1 + 全能力%累加)
```

**生命值**：
```
最终生命值 = 角色基础生命值 × (1 + 生命值%累加) + 固定生命值累加
```

### 6.2 增益叠加规则

1. **同名增益先加算**：攻击力+20% + +10% = +30%
2. **先固定值后百分比**
3. **不同名增益独立乘区**：以下乘区各自独立乘算

| 乘区 | 作用对象 | 公式 |
|------|---------|------|
| 伤害加成区 | 干员自身 | `1 + Σ` |
| 增幅区 | 干员自身 | `1 + Σ` |
| 易伤区 | 敌人 | `1 + Σ`（导电/燃烧等） |
| 脆弱区 | 敌人 | `1 + Σ`（碎甲等） |

> "法术伤害增加"提供全属性（灼热/寒冷/电磁/自然）伤害加成，非仅限于法术伤害。

### 6.3 技能伤害公式（常规伤害）

```
最终伤害 = 基础伤害区 × 暴击区 × 伤害加成区 × 伤害减免区 × 增幅区 × 虚弱区
         × 庇护区 × 脆弱区 × 易伤区 × 防御区 × 失衡易伤区 × 抗性区
         × 非主控减伤区 × 连击增伤区 × 特殊乘区
```

| 乘区 | 公式 |
|------|------|
| **基础伤害区** | `伤害倍率 × 对应属性 + 基础伤害提升值` |
| **暴击区（期望）** | `= 1 + 暴击率 × 暴击伤害` |
| **伤害加成区** | `= 1 + 伤害类型加成 + 技能类型加成 + 失衡伤害加成 + 其他` |
| **伤害减免区** | `= Π(1 - 伤害减免)` |
| **增幅区** | `= 1 + Σ增幅效果` |
| **虚弱区** | `= Π(1 - 虚弱效果)` |
| **庇护区** | `= 1 - max(庇护效果)` |
| **脆弱区** | `= 1 + Σ脆弱效果` |
| **易伤区** | `= 1 + Σ易伤` |
| **防御区** | 真实伤害=1；其他=`1 - 防御/(防御+100)` |
| **失衡易伤区** | 失衡时=1.3；其他=1 |
| **抗性区** | `= 1 - 抗性/100 + 无视抗性/100` |
| **非主控减伤区** | 非主控角色在场上时生效 |
| **连击增伤区** | `= 1 + 连击增伤`（详见 §5.6） |
| **特殊乘区** | 独立于以上乘区的客制化效果 |

> 注意：普通攻击不属于"技能"，全技能伤害提升仅提升战技、终结技和连携技，不包括普攻。下落攻击、处决攻击仍受益于普通攻击伤害加成。

### 6.4 法术异常/爆发伤害公式

```
异常伤害 = 倍率 × (1 + 异常等级) × 等级系数区 × 源石技艺强度区
```
- 等级系数区 = `1 + (等级 - 1) / 196`
- 源石技艺强度区 = `1 + 源石技艺强度 / 100`

| 反应 | 倍率 |
|------|------|
| 导电/腐蚀/燃烧/冻结 初始伤害 | `80% × (1 + 异常等级)` |
| 燃烧持续伤害（每秒） | `12% × (1 + 异常等级)` |
| 碎冰 | `120% × (1 + 异常等级)` |
| 法术爆发 | `160%` |

### 6.5 物理异常伤害公式

```
异常伤害 = 倍率 × (破防层数乘数) × 物理等级系数区 × (1 + 源石技艺强度/100)
```
- 物理等级系数区 = `1 + (等级 - 1) / 392`

| 反应 | 倍率 | 破防层数乘数 |
|------|------|-------------|
| 击飞/倒地 | 120% | 1（不随层数变化） |
| 碎甲 | 50% | `(破防层数 + 1)` |
| 猛击 | 150% | `(破防层数 + 1)` |

### 6.6 源石技艺强度增强公式

**附带效果增强**（碎甲/导电/腐蚀）：
```
增强数值 = 2 × 源石技艺强度 / (源石技艺强度 + 300)
增强后效果 = 原始效果 × (1 + 增强数值)
```

每点源石技艺强度效果：
- 猛击/燃烧/冻结/碎冰/法术爆发：伤害 +1%
- 碎甲/导电/腐蚀：伤害 +1%，附带效果增强
- 击飞/倒地：伤害 +1%，失衡值 +0.5%

### 6.7 乘区分类总结

**按作用对象**：

| 作用于干员自身 | 作用于敌人 |
|--------------|-----------|
| 伤害加成区、增幅区、暴击区 | 易伤区、脆弱区、抗性区 |
| 连击增伤区、源石技艺强度区 | 防御区、失衡易伤区 |

**按生效方式**：

| 加算（Σ） | 乘算（Π） | 特殊 |
|----------|----------|------|
| 伤害加成区、增幅区、脆弱区、易伤区 | 伤害减免区、各乘区之间 | 庇护区（取 max） |

### 6.8 伤害流程顺序

**常规技能伤害**：
```
① 计算攻击力 → ② 计算基础伤害区 → ③ 依次应用乘区 → ④ 最终伤害
```

**异常伤害**：
```
① 检查触发条件 → ② 状态添加 → ③ 检查反应触发 → ④ 造成异常伤害 → ⑤ 施加反应后效果 → ⑥ 状态消耗
```

### 9.2 核心决策：计算引擎放前端

**推荐**：核心计算引擎放在前端（TypeScript），理由：
1. 伤害计算需要实时反馈
2. 公式计算无需依赖数据库
3. 排轴模拟需在浏览器端多次对比

```

├── reactions/      elemental.ts / physical.ts
├── simulation/     timeline.ts / resource.ts / buffs.ts / state.ts
└── types/          character.ts / weapon.ts / equipment.ts / skill.ts / buff.ts / damage.ts / timeline.ts
```

## 10. 数据库设计规范

### 10.1 命名约定

- 所有字段需写中文注释
- 角色/武器/装备/配装名称及对应等级需做区分避免歧义
- 角色的可用武器类型字段名应与武器的类型字段名统一（`weapon_type` / `type`）
- 增益来源字段长度放宽到 200
- 所有表预留两个备用字段（`reserve1`, `reserve2`）

### 10.2 枚举值定义

| 枚举 | 值 |
|------|-----|
| 武器类型 | 单手剑、双手剑、长柄武器、手铳、施术单元 |
| 技能类型 | 普通攻击、战技、连携技、终结技、天赋一、天赋二、其他类型 |
| 伤害类型 | 灼热、寒冷、电磁、自然、物理、超域伤害、真实伤害、其他伤害 |
| 职业 | 突击、近卫、术士、重装、先锋、辅助 |
| 能力 | 力量、敏捷、智识、意志 |
| 装备部位 | 护甲、护手、配件 |
| 增益类型 | 常驻、限定 |
| 增益叠加方式 | 同名加算、独立乘区 |
| 技能等级 | 1~12 |

### 10.3 核心表结构

**角色表 (character)**：`id, name, icon(TEXT), rarity(4-6), level(1-90), base_hp(DECIMAL(12,4)), base_atk(DECIMAL(12,4)), base_str/agi/int/wil(DECIMAL(10,4)), main_attr, sub_attr, class, element, weapon_type, potential(0-5), trust_talent_level(1-4), reserve1, reserve2, created_at, updated_at`

**武器表 (weapon)**：`id, name, icon(TEXT), rarity(3-6), potential(0-5), type, level(1-90), base_atk(DECIMAL(12,4)), affix1_name/type/size/level/value, affix2_name/type/size/level/value, affix3_name/type/level/effect1/effect2/effect3/description, reserve1/2, created_at, updated_at`

**装备表 (equipment)**：`id, name, icon(TEXT), slot, level, base_def, set_name, attr1_name/type/refine/value/value_refine1/2/3, attr2_..., attr3_..., set_effect1_name/type/effect_type/value/description, set_effect2_name/type/effect_type/value/condition/duration/description, reserve1/2, created_at, updated_at`

**增益表 (gain)**：`id, name, source(200), gain_type, effect_category, effect_type, effect_value, value_type, stack_rule, target_scope, target_character_id, trigger_condition, duration, max_stacks, reserve1/2, created_at, updated_at`

**技能表 (skill)**：`id, character_id, name, type, damage_type, description, reserve1/2, created_at, updated_at`

**技能等级表 (skill_level)**：`skill_id, level(1-12), multiplier, created_at, updated_at` — 复合主键 `(skill_id, level)`

**技能动作与资源表 (skill_action) (v2.0+)**：`skill_id(PK), cast_time, pre_cast, post_cast, tech_cost(100), tech_return, tech_regen, chain_cd, ultimate_cd, energy_regen_self, energy_regen_condition, apply_attachment, apply_break, consume_attachment, consume_break, chain_trigger_condition, reserve1/2, created_at, updated_at`

**配队方案表 (team) (v1.2+)**：`id, name, character_a_id/build_a_id, character_b_id/build_b_id, character_c_id/build_c_id, character_d_id/build_d_id, created_at, updated_at`

### 13.5 API 接口设计（RESTful）

**基础数据**：`GET/POST/PUT/DELETE /api/characters|weapons|equipment|gains|skills`

**配装方案**：`GET/POST/PUT/DELETE /api/builds`

**配队方案**：`GET/POST/PUT/DELETE /api/teams`

**排轴方案**：`GET/POST/PUT/DELETE /api/rotations`

**计算**：
- `POST /api/calculate/character` — 单角色伤害计算
- `POST /api/calculate/team` — 配队伤害计算
- `POST /api/calculate/rotation` — 排轴模拟

**分享**：
- `POST /api/share/build|team|rotation/{id}` — 生成分享码
- `GET /api/import/{code}` — 通过分享码导入
